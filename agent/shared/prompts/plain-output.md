# 純文字輸出規格

**適用：** `output_format: plain`

---

## 輸出格式要求

- ❌ **不要使用** Markdown 格式（如 `**粗體**`、`*斜體*`、`` `代碼` ``）
- ✅ **使用** 純文字、標點符號和換行排版
- ✅ 可以用空行分隔段落
- ✅ 可以用簡單的符號（如 `-`、`•`）做列表
- ✅ 可以用數字做編號（如 `1.`、`2.`）

---

## 範例

### 正確範例

```
你好！我是你的助手。

有什麼我可以幫你的嗎？我可以：
- 回答問題
- 提供建議
- 幫你整理資料

請隨時告訴我你需要什麼協助。
```

### 錯誤範例

```
你好！我是你的**助手**。

有什麼我可以幫你的嗎？我可以：
- **回答問題**
- *提供建議*
- 幫你`整理資料`

請隨時告訴我你需要什麼`協助`。
```

---

## 注意事項

1. 保持語句簡潔清晰
2. 避免過長的段落（建議每段 < 100 字）
3. 使用自然語言，不需要特殊格式
