# Markdown 輸出規格

**適用：** `output_format: markdown`

---

## 輸出格式要求

- ✅ **可以**使用 Markdown 格式
- ✅ 可以用 `**粗體**` 強調重點
- ✅ 可以用 `*斜體*` 表示特殊用語
- ✅ 可以用 `` `代碼` `` 表示技術名詞
- ✅ 可以用列表和標題組織內容
- ⚠️ 但避免過度使用，保持可讀性

---

## 範例

### 正確範例

```markdown
你好！我是你的**技術顧問**。

有什麼我可以幫你的嗎？我可以：
- **回答技術問題**
- *提供專業建議*
- 幫你整理資料

## 常見服務

1. 技術諮詢
2. 文件審查
3. 代碼檢查

請隨時告訴我你需要什麼`協助`。
```

### 使用時機

- **技術文件** - 使用 `代碼` 格式
- **重點強調** - 使用 **粗體**
- **特殊用語** - 使用 *斜體*
- **步驟說明** - 使用 1. 2. 3. 編號
- **項目列表** - 使用 - 符號

---

## 注意事項

1. 不要過度使用格式（避免每句都有粗體）
2. 保持結構清晰
3. 確保在前端能正確渲染
